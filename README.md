# 独乐 SOLO ARCADE

一个人，也能玩得很尽兴。一个可安装、可离线、适配手机 / iPad / 电脑的单机小游戏站。

包含 **10 款完整可玩的轻量小游戏**：2048、贪吃蛇、方块消除、扫雷、数独、五子棋（人机）、打砖块、记忆翻牌、数字华容道、原创星轨穿梭。全部游戏逻辑和封面插画均随项目提供，无需外部 API，无账号、无广告、无追踪脚本。

## 本地打开

最快的方法：下载 [电脑离线包](./downloads/solo-arcade-offline.zip)，完整解压后双击 `首页.html`，并保留 `play` 文件夹。也可直接下载本仓库的 `offline.html`，用现代浏览器打开。此文件内嵌全部代码及插画，不需要服务器或网络。

开发模式需要 Node.js 20 或更新版本，没有第三方依赖：

```sh
npm run dev
# 打开 http://localhost:4173

npm test
npm run build
```

`npm run build` 重新生成原创插画、PWA 图标、10 个独立游戏页面、单文件兼容版、独立页面离线 ZIP 与 Service Worker 内容版本。修改源文件后请运行该命令，并提交生成的文件。

## GitHub Pages

仓库根目录即可作为静态网站发布，所有资源使用相对路径，支持 `/Single_Player_Station/` 子路径。

项目包含 `Publish game station` 自动发布工作流。每次推送到 `main`，会检查游戏规则、生成离线包并发布到 GitHub Pages。

1. 在仓库 **Settings → Pages** 中，确认 **Source** 设为 **GitHub Actions**。
2. 在 **Actions → Publish game station** 查看部署结果；必要时可点击 **Run workflow** 手动发布。
3. 等待部署成功，使用工作流或 Pages 设置页显示的正式网址访问。

预期地址为 `https://dns0129.github.io/Single_Player_Station/`，以 GitHub Pages 返回的实际部署状态为准。仅将文件推送到 GitHub 不代表 Pages 已启用。

## 安装客户端与离线使用

采用 **PWA 网页客户端**，当前版本不提供 App Store / APK / EXE / DMG 原生安装包。

- **iPhone / iPad**：用 Safari 访问 HTTPS 网站 → 分享 → 添加到主屏幕。
- **Android**：Chrome / Edge 菜单 → 安装应用，或添加到主屏幕。
- **Windows / macOS / Linux**：Chrome / Edge 地址栏的安装按钮，或浏览器菜单 → 安装网站为应用。Mac Safari 可添加到程序坞。
- **电脑离线包**：完整解压 ZIP 后双击 `首页.html`，无需安装。

首次联网访问后，等待右上角显示「离线已就绪」。全部十款游戏与图片将缓存到当前设备，之后即可断网进入。PWA 要求 HTTPS 或 localhost；直接打开 `offline.html` 时可玩游戏，但不能执行 PWA 安装。

## 独立游戏页面

首页位于 `/`，每个游戏都可以直接访问、收藏网址或刷新：

- 打砖块：[`play/breakout/`](https://dns0129.github.io/Single_Player_Station/play/breakout/)
- 其余页面：`play/twenty48/`、`play/snake/`、`play/blocks/`、`play/mines/`、`play/sudoku/`、`play/gomoku/`、`play/memory/`、`play/slide/`、`play/orbit/`。

页面由 `scripts/pages.mjs` 生成，各有操作说明、收藏和返回首页入口；PWA 会一并缓存全部独立页面，断网仍可切换游戏。旧的 `#play=游戏ID` 链接会转到相应页面。

## 打砖块：100 关冒险

10 个主题章节，各有 10 个不同关卡，包含强化砖、连锁爆破砖以及逐渐提高的球速。普通砖已改为 12×12 的小方块，球直径为一块砖的宽度（12）。所有关卡以原砖量的三倍为基准，结合 1–5 级难度与每关 7–13 件道具调整到约 3–3.6 倍；选关图和游戏中会显示砖量、难度及道具数量。灰蓝色墙体由同尺寸小方块组成，普通球与穿透球撞上都会反弹，爆炸也无法破坏墙体；墙体不计入通关目标，阵型始终保留绕行空间。全部关卡可自由选择；通关记录、每关最高分和 1–3 枚星章会自动保存。重新打开会继续上次选择或下一待挑战关卡；重开本关保留已取得的记录。

掉落道具可直接点击/轻触、通过键盘聚焦后回车，或用挡板接住。八种道具为延长挡板、三重球、爆炸球、穿透球、慢速时间、底部护盾、额外生命、双倍积分。限时效果能够叠加，多球最多七颗。

爆炸球碰到砖块会造成范围伤害，同时提供三次主动爆破机会。按 **E** 或点 **引爆** 可让所有在场弹球同时产生范围爆炸。红色爆破砖会连锁引爆周围砖块；强化砖上的圆点显示剩余耐久。每关首次击碎砖块保证掉落一件道具，其余道具按照该关的预定数量随清砖进度分批掉落，最后一批会在清除约 82% 的砖块前后出现。

## 游戏与操作

| 游戏 | 操作 | 功能 |
| --- | --- | --- |
| 2048 | 滑动 / 方向键 / WASD / 屏幕按钮 | 自动保存未结束棋盘、撤回一步 |
| 贪吃蛇 | 滑动 / 方向键 / WASD / 屏幕按钮 | 吃果实加速、碰撞结算 |
| 方块消除 | 方向键 / 触屏按钮，空格落下 | 七种方块、预览、落点提示、升级 |
| 扫雷 | 点击打开，右键或插旗模式标旗 | 首次点击及周围安全、自动展开 |
| 数独 | 点击选格 + 数字键或数字面板 | 唯一解题目、冲突提示、提示、自动保存 |
| 五子棋 | 点击交叉点，或方向键 + 回车 | 人机对弈、电脑进攻与防守 |
| 打砖块 | 鼠标 / 拖动 / 左右键，空格发球，E 引爆 | 100 关自由选关、8 种道具、强化与爆破砖、星章与进度保存 |

| 数字华容道 | 点击 / 方向键 / 滑动 | 可解随机开局、自动保存 |
| 星轨穿梭 | 拖动 / 方向键 / WASD / 屏幕按钮 | 原创躲避玩法、收集星星、三格护盾 |

游戏内按 `P` 或 `Esc` 暂停，离开页面时自动暂停；点击「返回首页」回到游戏库。音效默认关闭，可以在游戏窗口中开启。

## 本机数据

收藏、最近玩过、最高分与解谜存档使用浏览器 localStorage。不同设备不会自动同步。清除浏览器数据会删除记录；隐私模式或部分浏览器的文件模式可能限制持久保存。可在右上角「玩」→ 游戏记录中清除本机数据。

## 验证

`npm test` 使用 Node.js 内置测试检查合并规则、扫雷首击安全、数独唯一解、五子棋胜负与 AI、华容道可解性、方块消行等；打砖块额外检查 100 关唯一性、碰撞、连锁爆炸、八种道具、多球、护盾、结算及进度保存，并使用自动挡板通过真实碰撞与道具完成全部 100 关的试玩。浏览器验收脚本使用本机已安装的 Playwright 与 Chromium；可设置 `PLAYWRIGHT_PATH` 和 `CHROMIUM_PATH` 指定其位置。
